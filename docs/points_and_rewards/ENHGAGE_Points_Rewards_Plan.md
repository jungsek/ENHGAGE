# ENHGAGE Points & Rewards System Plan

## Executive Summary

This document outlines the comprehensive plan for the **Points Page** and **Rewards Page** for ENHGAGE, the NHG youth wellness companion app. The rewards system is designed to drive engagement while authentically connecting users to Singapore's healthcare ecosystem through strategic partnerships.

---

## Part 1: Points Page Design

### 1.1 Overview

The Points Page serves as the central hub where users can view their accumulated points, understand how they earned them, and track their progress toward rewards.

### 1.2 Key UI Components

#### Header Section
- **Total Points Balance**: Large, prominent display (e.g., "🌟 2,450 Points")
- **Points This Week**: Secondary metric showing recent earnings
- **Streak Multiplier Status**: Visual indicator if hot streak bonus is active (1.5x or 2x)

#### Points Breakdown Card
Display points by category with icons aligned to mascot roles:

| Category | Icon | Example Actions |
|----------|------|-----------------|
| **Move & Exercise** (Olah) | 🏃 | Complete daily steps, log workouts, attend Moving Free sessions |
| **Eat & Nutrition** (Lylah) | 🥗 | Complete Walking Foodpedia challenge, log meals |
| **Mental Wellness** (Ellah) | 🧘 | Meditation sessions, gratitude journaling, mood check-ins |
| **Community** | 👥 | Invite friends, share achievements, attend CHP events |
| **Learning** | 📚 | Complete health quizzes, read health tips, watch NHG videos |

#### Points History Timeline
- Scrollable list showing recent point-earning activities
- Each entry shows: Date, Activity, Points Earned, Mascot involved
- Filterable by category and date range

#### Progress Trackers
- **Tier Progress Bar**: Show progress to next tier (Bronze → Silver → Gold → Diamond)
- **Rewards Preview**: "You're 550 points away from a FairPrice $5 voucher!"
- **Monthly Goal**: Optional user-set target with progress visualization

### 1.3 Points Earning Structure

#### Base Points (Daily Activities)

| Activity | Points | Daily Cap |
|----------|--------|-----------|
| Complete daily step goal (8,000 steps) | 50 | 50 |
| Log a meal | 10 | 30 (3 meals) |
| Complete a workout (15+ min) | 30 | 60 (2 workouts) |
| Morning mood check-in | 10 | 10 |
| Evening reflection | 10 | 10 |
| Complete a health quiz | 20 | 40 (2 quizzes) |
| Read a health article | 5 | 15 (3 articles) |

**Daily Maximum**: ~235 points/day

#### Bonus Points

| Achievement | Bonus Points |
|-------------|--------------|
| **Streak Bonuses** | |
| Warm streak active (7+ days) | 1.5x multiplier on base points |
| Hot streak active (21+ days) | 2x multiplier on base points |
| **Weekly Challenges** | |
| Complete weekly challenge | 100-200 points |
| Perfect week (all daily goals) | 300 points |
| **Program Participation** | |
| Register for NHG/CHP programme | 50 points |
| Attend NHG/CHP programme | 150 points |
| Complete a multi-week programme | 500 points |
| **Social Bonuses** | |
| Invite a friend (who joins) | 200 points |
| First friend workout together | 100 points |
| Share achievement to social media | 25 points |

### 1.4 Tier System

| Tier | Points Required | Benefits |
|------|-----------------|----------|
| **Bronze** | 0 | Base rewards access |
| **Silver** | 2,500 | 5% bonus points, exclusive challenges |
| **Gold** | 7,500 | 10% bonus points, early access to new rewards |
| **Diamond** | 15,000 | 15% bonus points, VIP NHG event invites, exclusive merchandise |

## Part 5: Points Economy Balance

### 5.1 Economic Model

**Target Economics:**
- User earns ~150-200 points/day on average
- Entry-level reward ($5 voucher) = ~7-10 days of engagement
- Premium reward (movie ticket) = ~20-25 days of engagement

### 5.2 Points-to-Value Ratio

| Points | Approximate Value | Redemption Examples |
|--------|-------------------|---------------------|
| 300 | $1 | Digital goods, stickers |
| 1,500 | $5 | Grocery voucher, pool entry |
| 3,000 | $10 | ActiveSG credits, retail voucher |
| 4,500 | $15 | Premium vouchers |

**Conversion Rate:** ~300 points = $1 value

### 5.3 Anti-Gaming Measures

To prevent exploitation:
- Daily earning caps per category
- Verification for programme attendance (QR codes)
- Suspicious activity detection (rapid point accumulation)
- Cool-down periods between same-type redemptions

## Summary

The ENHGAGE Points & Rewards system is designed to:

1. **Drive daily engagement** through achievable point-earning activities
2. **Connect to Singapore's health ecosystem** via NHG, HPB, and ActiveSG
3. **Offer meaningful rewards** that appeal to 18-35 year olds
4. **Leverage FREE NHG programmes** as value-added rewards
5. **Scale sustainably** with balanced points economy

**Key Recommendation:** Launch with HPB eVoucher integration as the primary reward mechanism, as it provides immediate access to popular merchants (FairPrice, Watsons, Golden Village) through an established government partnership that aligns with ENHGAGE's health mission.
